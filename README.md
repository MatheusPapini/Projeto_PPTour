# 🚂 PPTour

### Plataforma informativa e dinâmica do Expresso Turístico de Paranapiacaba

Projeto desenvolvido em equipe como parte da formação no Instituto PROA.

O PPTour tem como objetivo promover o Expresso Turístico de Paranapiacaba por meio de uma plataforma dinâmica e interativa.

**Minha participação:**
- Desenvolvimento full-stack em equipe.
- Participação nas entregas incrementais do projeto.
- Utilização da metodologia Kanban.
- Colaboração na implementação de funcionalidades.

🔗 Repositório: *https://pptour.vercel.app/*
